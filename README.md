# MCP Authorization

Reusable utilities and configuration examples for exploring authentication and authorization of Model Context Protocol (MCP) servers through MuleSoft Omni Gateway.

## Scope

- RSA key generation and JWT issuance
- JWT authentication
- Persona-based MCP authorization
- Cedar authorization policies
- MCP tool discovery and invocation controls

## Environment

- MuleSoft Managed Omni Gateway
- MuleSoft MCP Bridge
- Brilliant Mule Service Desk API
- Witsy MCP client

## Documentation

Configuration notes and findings are maintained in `docs/`.
