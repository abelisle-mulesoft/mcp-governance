# Documentation

This directory contains technical documentation from hands-on experiments exploring MuleSoft's MCP integration, management, and governance capabilities. This documentation is developed incrementally as experiments are completed, preserving configurations, test scenarios, observations, findings, and limitations for future reference and reuse.

## Documents

| Document | Description |
| --- | --- |
| [MCP Governance](mcp-governance.md) | Exploration of MCP Bridge and Omni Gateway governance policies, including tool discovery, access control, payload optimization, PII detection, tool mapping, and progressive disclosure. |
| [JWT Authentication](jwt-authentication.md) | Implementation and testing of JWT authentication using locally generated RSA keys and Omni Gateway JWT Validation. |
| [MCP Authorization](mcp-authorization.md) | Implementation and testing of persona-based MCP tool authorization using Cedar policies and Omni Gateway MCP ABAC. |

The `images/` directory contains screenshots and other visual assets referenced by the technical documentation.
